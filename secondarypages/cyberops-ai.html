01. Project Overview

Security analysts waste 15–20 minutes per investigation gathering data from multiple sources, correlating logs, and writing reports. Junior analysts often miss critical context clues. Manual processes don't scale during active incidents. CyberOps AI Assistant solves this with an intelligent automation layer: feed it an IP address, get a professional threat report in under 60 seconds.

The system aggregates WHOIS data, Tor exit node status, geolocation, and system log activity in parallel — then passes everything to Google Gemini AI for expert-level analysis and risk scoring. Three modes (Quick 30s / Deep 60s / Full 90s) let you match depth to urgency.

"The goal wasn't to replace analyst judgment — it was to eliminate the 15 minutes of mechanical data gathering that happens before any judgment can be applied."

02. Key Features
Automated OSINT
Gathers WHOIS registration, checks Tor exit node status, performs geolocation, and correlates with threat feeds automatically in parallel threads.
Log Correlation
Searches auth.log, syslog, Apache/nginx access logs, and Suricata EVE JSON to build a complete activity timeline for any IP.
AI-Powered Analysis
Google Gemini AI receives all gathered data and returns expert-level threat assessment, risk scoring (1–10), and actionable remediation steps.
Professional Reports
Generates timestamped, formatted security reports suitable for management escalation, ticketing systems, and compliance documentation.
Three Analysis Modes
Quick (30s) for rapid triage, Deep (60s) for log correlation, Full (90s) for complete AI executive summary and management-ready report.
n8n Integration
Designed to slot into n8n workflow automation — trigger an investigation automatically when a Suricata alert fires or a log anomaly is detected.

04. Usage
MODE 01 — QUICK (30s)
Rapid triage — WHOIS, Tor check, AI threat assessment
Best for initial alert triage when you need a fast answer on whether an IP is worth investigating further.
./run_analysis.sh 185.220.101.1 quick

# Output: WHOIS data, Tor exit node status,
# geolocation, AI threat tier (LOW/MED/HIGH/CRITICAL)
MODE 02 — DEEP (60s)
Log correlation — all system logs searched for activity timeline
Includes everything from Quick, plus a system-wide log search that builds a complete activity timeline for the target IP.
./run_analysis.sh 185.220.101.1 deep

# Output: Everything from quick + log timeline,
# pattern recognition, frequency analysis
MODE 03 — FULL (90s)
Complete investigation — AI executive summary, management-ready report
Maximum depth: AI-generated executive summary with risk score 1–10, prioritized recommended actions, and a formatted report ready for ticket or management escalation.
./run_analysis.sh 185.220.101.1 full

# Output: Everything from deep + AI executive summary,
# risk score, recommended actions, full report file
05. Installation
Requires: Kali Linux / Ubuntu / Debian, Python 3.13+, Google Gemini API key (free tier works), sudo access for log reading.
git clone https://github.com/karim871/cyberops-ai.git
cd cyberops-ai

# Create isolated environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install google-genai python-dotenv

# Configure API key (never commit this file)
echo "GOOGLE_API_KEY=your_key_here" > .env

# Make executable and test
chmod +x threat_analyzer.py run_analysis.sh
./run_analysis.sh 8.8.8.8 quick
