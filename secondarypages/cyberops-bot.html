01. Project Overview

A self-hosted threat intelligence pipeline built with n8n running in Docker. When a Telegram message containing an IP address is sent to the bot, it extracts the IP via a JavaScript regex, fires parallel HTTP requests to AbuseIPDB, VirusTotal, and AlienVault OTX, runs a weighted risk scoring algorithm across all three feeds, then delivers a formatted threat report back to the Telegram chat — all in under 3 seconds.

The project evolved from a Python CLI tool for single-feed lookups into a fully automated multi-source pipeline with real-time Telegram delivery. The n8n workflow handles API orchestration with zero custom server infrastructure — just Docker and an ngrok tunnel for the webhook endpoint.

"Three feeds, one message, under three seconds. That's the delta between a SOC analyst spending 5 minutes on a manual lookup and catching the next IOC before the analyst even opens a browser tab."

03. Risk Scoring Algorithm

Three sources contribute to a weighted 0–100 composite score. Weights reflect source reliability and signal density — AbuseIPDB and VirusTotal carry equal weight, OTX acts as a supporting signal.

SCORING WEIGHTS
AbuseIPDB — 40 pts max (confidence × 0.4)
VirusTotal — 40 pts max (mal×3 + sus×1.5, capped)
AlienVault OTX — 20 pts max (pulses × 5, capped)
Total = sum of three, capped at 100
RISK TIERS
LOW — Score 0–24 (no action needed)
MEDIUM — Score 25–49 (monitor)
HIGH — Score 50–74 (investigate)
CRITICAL — Score 75–100 (block immediately)
// n8n Function Node — Risk Scoring Engine
const abuseScore   = $('AbuseIPDB').first().json.data.abuseConfidenceScore;
const vtMalicious  = $('VirusTotal').first().json.data.attributes.last_analysis_stats.malicious;
const vtSuspicious = $('VirusTotal').first().json.data.attributes.last_analysis_stats.suspicious;
const otxPulses    = $('OTX').first().json.pulse_info.count;

const abusePoints = Math.min(abuseScore * 0.4, 40);
const vtPoints    = Math.min((vtMalicious * 3) + (vtSuspicious * 1.5), 40);
const otxPoints   = Math.min(otxPulses * 5, 20);
const total       = Math.round(abusePoints + vtPoints + otxPoints);

const level = total >= 75 ? 'CRITICAL' : total >= 50 ? 'HIGH' :
              total >= 25 ? 'MEDIUM'   : 'LOW';

return [{ json: { score: total, level, abusePoints, vtPoints, otxPoints } }];
04. Project Evolution

Four phases from Python CLI prototype to a fully automated Telegram-delivered pipeline.

PHASE 01 — PYTHON CLI
Single-source lookup, terminal output
Initial version queried AbuseIPDB only via a Python CLI script. Took an IP as an argument, returned raw JSON parsed into a readable summary. Established the IOC enrichment concept and API integration pattern.
PHASE 02 — MULTI-SOURCE
VirusTotal and OTX added — Python multi-threaded
Expanded to three feeds using Python's concurrent.futures.ThreadPoolExecutor to query all three APIs in parallel, reducing total latency. Output remained CLI — structured JSON with per-source breakdown and an aggregate risk score.
PHASE 03 — N8N AUTOMATION
Workflow migrated to n8n, Docker deployment
Rebuilt the pipeline in n8n running in Docker — HTTP Request nodes replace the Python API calls, a JavaScript Function node handles IP extraction and risk scoring. ngrok tunnels the webhook for Telegram delivery. No custom server infrastructure required.
PHASE 04 — TELEGRAM DELIVERY
Real-time bot reports delivered to Telegram chat
Telegram bot integration via BotFather. Any IP pasted into the chat triggers the full pipeline — AbuseIPDB + VirusTotal + OTX queried in parallel, risk score computed, formatted report with risk meter and remediation advice delivered back in under 3 seconds.
05. Implementation
STEP 01 — DEPLOY N8N
Self-hosted n8n in Docker + ngrok webhook tunnel
Run n8n locally with Docker, expose the webhook port externally via ngrok so Telegram can deliver updates.
docker run -it --rm \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

# Expose webhook to internet:
ngrok http 5678
STEP 02 — TELEGRAM BOT
BotFather setup + webhook registration
Create the bot via BotFather, get the token, register the ngrok URL as the webhook so Telegram pushes updates to n8n.
# Register webhook with Telegram API:
curl -X POST \
  "https://api.telegram.org/bot{TOKEN}/setWebhook" \
  -d "url=https://your-ngrok-id.ngrok.io/webhook/cyberops"

# Verify:
curl "https://api.telegram.org/bot{TOKEN}/getWebhookInfo"
STEP 03 — IP EXTRACTION
JavaScript Function node — regex parse from Telegram text
A Function node parses the incoming Telegram message and extracts the first valid IPv4 address using regex.
// n8n Function Node — IP Extraction
const text = $input.first().json.message?.text || '';
const ipRegex = /\b(?:(?:25[0-5]|2[0-4]\d|[01]?\d\d?)\.){3}(?:25[0-5]|2[0-4]\d|[01]?\d\d?)\b/;
const match = text.match(ipRegex);

if (!match) {
  return [{ json: { error: 'No valid IP found in message.' } }];
}

return [{ json: { ip: match[0], chatId: $input.first().json.message.chat.id } }];
STEP 04 — PARALLEL API CALLS
Three HTTP Request nodes run simultaneously
Three HTTP Request nodes branch in parallel from the IP extraction node — AbuseIPDB, VirusTotal, and AlienVault OTX all fire at the same time, reducing total API latency to the slowest single response rather than the sum of all three.
  • AbuseIPDB: GET /api/v2/check?ipAddress={ip}&maxAgeInDays=90
  • VirusTotal: GET /api/v3/ip_addresses/{ip}
  • AlienVault OTX: GET /api/v1/indicators/IPv4/{ip}/general
STEP 05 — RESPONSE FORMATTING
Structured Telegram message with risk meter
A final Function node assembles the report — risk meter emoji, score, per-source findings, and a remediation recommendation based on the risk tier.
// n8n Function Node — Response Formatter
const { ip, score, level } = $input.first().json;
const dots  = Math.round(score / 25);
const meter = '🟢'.repeat(Math.min(dots, 4)) + '⚪'.repeat(Math.max(4 - dots, 0));
const emoji = { LOW: '🟢', MEDIUM: '🟡', HIGH: '🟠', CRITICAL: '🔴' }[level];
const actions = {
  LOW:      '✅ No immediate action needed.',
  MEDIUM:   '⚠️ Monitor this IP. Check recent firewall logs.',
  HIGH:     '🔶 Investigate now. Review all connections from this IP.',
  CRITICAL: '🚫 Block this IP immediately.\n🔍 Review firewall logs.\n📋 Check for any active connections.'
};

return [{
  json: {
    message: `🌐 IP Threat Intelligence Report\n\nIP: ${ip}\n\n📊 RISK ASSESSMENT\nRisk Meter: ${meter}\n${emoji} Risk Score: ${score}/100 — ${level}\n\n💡 RECOMMENDATIONS\n${actions[level]}\n\n_This message was sent automatically with n8n_`
  }
}];
