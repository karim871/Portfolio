D1. System Management — 23%

Boot Process

  • BIOS/UEFI → GRUB2 → kernel → initramfs → systemd
  • GRUB2 config: /boot/grub2/grub.cfg
  • Kernel parameters in /etc/default/grub
  • systemd targets: multi-user, graphical, rescue, emergency
  • systemctl get-default / set-default

Storage & Filesystems

  • Partitioning: fdisk, parted, lsblk
  • LVM: PV → VG → LV; pvcreate vgcreate lvcreate
  • Extend LVM: lvextend -L +10G then resize2fs / xfs_growfs
  • RAID: levels 0, 1, 5, 6, 10 — mdadm
  • Mount: /etc/fstab, UUID vs device path
  • Filesystem check: fsck (unmounted), xfs_repair

Network Configuration

  • nmcli for NetworkManager (RHEL/Fedora)
  • ip addr, ip route, ip link
  • Static IP: /etc/network/interfaces (Debian) or nmcli
  • DNS config: /etc/resolv.conf, /etc/hosts
  • Bonding/bridging basics; VLAN tagging with ip link

Shell Operations

  • Redirection: > >> 2> 2>&1 /dev/null
  • Pipes, process substitution, here-docs
  • Environment: export, .bashrc vs .bash_profile
  • Path management; which, type, command -v

Backup & Restore

  • tar czf backup.tar.gz /dir — create compressed archive
  • rsync -av --delete src/ dest/ — incremental sync
  • Full vs incremental vs differential backup strategies
  • LVM snapshots for live backups
  • Test restores — a backup not tested is not a backup

Virtualization

  • KVM + QEMU for Linux VMs; virsh management
  • Type 1 (bare-metal) vs Type 2 (hosted) hypervisors
  • VM snapshots/checkpoints; disk image formats (qcow2, raw)
  • virt-manager GUI; qemu-img for image ops
D2. Services & User Management — 20%

User & Group Management

  • useradd, usermod, userdel -r
  • groupadd, gpasswd, id, groups
  • Password aging: chage -l user, passwd -e
  • /etc/passwd, /etc/shadow, /etc/group
  • sudoers: visudo — never edit directly

File Permissions & ACLs

  • chmod octal and symbolic; chown, chgrp
  • Special bits: setuid (4), setgid (2), sticky (1)
  • umask: default 022 → files 644, dirs 755
  • ACLs: getfacl, setfacl -m u:user:rwx file
  • Extended attributes: lsattr, chattr +i (immutable)

systemd Services

  • systemctl start|stop|restart|status service
  • systemctl enable|disable — boot persistence
  • Unit file types: service, socket, timer, mount, target
  • journalctl -u service -f — follow service logs
  • systemd-analyze blame — boot time per unit

Package Management

  • Debian/Ubuntu: apt, dpkg
  • RHEL/Fedora: dnf, rpm
  • SUSE: zypper
  • Repos: /etc/apt/sources.list, /etc/yum.repos.d/
  • GPG signing keys; rollback/history with dnf

Containers — Docker & Podman

  • docker run -d -p 80:80 --name web nginx
  • docker ps, docker exec -it, docker logs
  • Images: docker pull, docker build, Dockerfile
  • Volumes: -v /host:/container for persistence
  • Podman: rootless by default; podman is drop-in replacement
  • Networks: bridge (default), host, none, overlay

Process Management

  • ps aux, top, htop, pgrep, pkill
  • Signals: kill -9 (SIGKILL), kill -15 (SIGTERM)
  • Priority: nice -n 10 cmd, renice -n -5 PID
  • Job control: bg, fg, jobs, nohup, tmux
  • Cron: crontab -e; systemd timers as modern alternative
D3. Security — 18%

SSH Hardening

  • Disable password auth: PasswordAuthentication no
  • Disable root login: PermitRootLogin no
  • Change default port, restrict AllowUsers
  • Key management: ssh-keygen, ssh-copy-id
  • ~/.ssh/authorized_keys permissions must be 600
  • SSH tunnels: -L local, -R remote, -D SOCKS

Firewalls

  • nftables: modern replacement for iptables
  • firewalld: firewall-cmd --add-port=443/tcp --permanent
  • UFW (Ubuntu): ufw allow 22, ufw enable
  • iptables basics: INPUT, OUTPUT, FORWARD chains; ACCEPT/DROP
  • Default-deny policy: iptables -P INPUT DROP

SELinux & AppArmor

  • SELinux modes: enforcing, permissive, disabled
  • getenforce, setenforce 1, sestatus
  • Context: ls -Z, chcon, restorecon
  • Booleans: getsebool -a, setsebool -P
  • AppArmor: aa-status, aa-enforce, aa-complain

Cryptography

  • LUKS full-disk encryption: cryptsetup luksFormat
  • GPG: gpg --gen-key, encrypt, sign, verify
  • Hashing: sha256sum, md5sum for integrity checks
  • TLS certs: openssl req -x509, CA chains
  • File integrity: aide for baseline + comparison

OS Hardening

  • Minimal installs — remove unused packages and services
  • disable unused services: systemctl disable --now bluetooth
  • PAM: /etc/pam.d/ — account lockout, password complexity
  • Audit: auditd, ausearch, aureport
  • Restrict su: pam_wheel module

Compliance & Scanning

  • Lynis: lynis audit system — hardening score
  • OpenSCAP: automated compliance scanning
  • Log retention: /etc/logrotate.d/ configuration
  • Principle of least privilege for accounts and processes
  • Separation of duties in sudoers rules
D4. Automation, Orchestration & Scripting — 17%

Bash Scripting

  • Variables: VAR="value", $VAR, ${VAR:-default}
  • Conditionals: if [[ $x -eq 1 ]]; -f, -d, -z, -n
  • Loops: for f in *.log; do; while read line
  • Exit codes: $?; use set -e for fail-fast scripts
  • Functions: function name() { ... }; local variables

Text Processing

  • grep -rn "pattern" /dir — recursive search with line numbers
  • sed -i 's/old/new/g' file — in-place replacement
  • awk '{print $1, $3}' file — field extraction
  • sort | uniq -c | sort -rn — frequency counting
  • cut -d: -f1 /etc/passwd — delimiter-based cutting

Ansible

  • Agentless — pushes over SSH; YAML playbooks
  • Inventory: /etc/ansible/hosts or custom file
  • Ad-hoc: ansible all -m ping, -m shell -a "cmd"
  • Playbook: tasks with modules (apt, yum, copy, service, user)
  • Idempotency — running twice produces same result
  • Roles for reusable, organized automation

Git Version Control

  • git clone, add, commit -m, push, pull
  • Branching: git checkout -b feature, merge, rebase
  • Undo: git revert (safe), git reset --hard (destructive)
  • Stash: git stash, git stash pop
  • Secrets: never commit — use .gitignore and vault tools

Python (Foundational)

  • Virtual environments: python3 -m venv venv
  • Package management: pip install, requirements.txt
  • File I/O, string manipulation, list comprehensions
  • subprocess module for shell command execution
  • sys.exit() with exit codes — important for scripting

Puppet

  • Agent-based (pull model) — agents pull from Puppet master
  • Push model (Ansible) vs pull model (Puppet) — exam distinction
  • Puppet DSL for resource declarations: package, file, service
  • Catalog compilation; agent runs every 30 min by default
  • Idempotency: same as Ansible — desired state enforcement
D5. Troubleshooting — 22%
The troubleshooting domain is the second-largest (22%) and heavily scenario-based. The methodology matters as much as the commands — know the six-step process: identify → hypothesize → test → remediate → verify → document.

Boot Troubleshooting

  • GRUB rescue prompt: set root, linux, initrd, boot
  • Kernel panic: check dmesg, bad initramfs, missing modules
  • systemd failures: systemctl list-units --failed
  • Emergency/rescue mode: append systemd.unit=emergency.target to kernel line
  • chroot recovery from live media

Performance Analysis

  • CPU: top, mpstat, sar — watch %wa (I/O wait)
  • Memory: free -h, vmstat — check swap usage
  • Disk I/O: iostat -x 1, iotop
  • Network throughput: iftop, nethogs, ss -s
  • Runaway processes: ps aux --sort=-%cpu

Network Troubleshooting

  • Layer 3: ping, traceroute, check default gateway
  • DNS: dig, nslookup, check /etc/resolv.conf
  • Port/service: ss -tlnp, nc -zv host port
  • Capture: tcpdump -i eth0 -n 'port 80'
  • MTU issues: ping -M do -s 1472 gw

Log Analysis

  • journalctl -xe — extended recent journal output
  • journalctl -u sshd --since "1 hour ago"
  • /var/log/auth.log (Debian) or /var/log/secure (RHEL)
  • /var/log/syslog, /var/log/messages
  • dmesg | tail -20 — recent kernel messages

Storage Issues

  • Disk full: df -h, du -sh /* to find large dirs
  • Inode exhaustion: df -i — full inodes = no new files
  • Read-only filesystem: mount -o remount,rw /
  • fsck on unmounted ext4: fsck -y /dev/sdb1
  • SMART: smartctl -a /dev/sda for disk health

Application & Service Failures

  • Permission denied: check ls -la, SELinux context, ls -Z
  • Port conflicts: ss -tlnp | grep :80
  • Dependency order: ExecStartPre, After= in unit files
  • Library issues: ldd /usr/bin/app, ldconfig
  • Core dumps: ulimit -c unlimited; analyze with gdb
06. Command Quick Reference
# ── SYSTEM ──────────────────────────────────────────────────────
uname -r                   # kernel version
lscpu                      # CPU info
lsblk                      # block devices
lsmod / modprobe / rmmod   # kernel modules
dmesg | grep -i error      # kernel errors

# ── STORAGE ─────────────────────────────────────────────────────
lsblk -f                   # filesystems + UUIDs
blkid                      # UUID lookup
mount -o remount,rw /
pvdisplay / vgdisplay / lvdisplay

# ── PROCESSES ───────────────────────────────────────────────────
ps aux --sort=-%mem | head -10
lsof -p PID                # open files by process
strace -p PID              # trace system calls

# ── NETWORK ─────────────────────────────────────────────────────
ip -br addr                # brief interface list
ip route show
ss -tulnp                  # all listening sockets with PIDs
tcpdump -i any -n -c 100   # 100 packets any interface

# ── SECURITY ────────────────────────────────────────────────────
last / lastb               # login / failed login history
who / w / id
passwd -S user             # password status
getent passwd user         # user info from any source (LDAP-aware)
chage -l user              # password expiry info

# ── LOGS ────────────────────────────────────────────────────────
journalctl -p err -b       # errors since last boot
journalctl --disk-usage
ausearch -m USER_LOGIN -ts today   # audit: today's logins
